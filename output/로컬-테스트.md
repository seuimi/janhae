# 잔해 로컬 서버 테스트

이 폴더의 파일로, 이미 켜 둔 Paper 서버에 플러그인을 넣고 아래 순서대로 확인한다. 플러그인 코드는 고치지 않는다. 막히면 그 단계의 채팅, 화면, `logs/latest.log` 오류를 적고 다음 단계로 넘어간다.

같은 폴더에 있는 파일:

- `janhae-1.0.0.jar` — 서버 `plugins`에 넣는 플러그인
- `janhae-pack.zip` — 클라이언트 리소스팩. 무기와 갑옷 모습이 들어 있다.

## 서버 조건

- Paper **26.3**, Java **25**
- 테스트하는 플레이어는 오피여야 한다. 서버 콘솔에서 `op <닉네임>`
- 서버가 26.3이 아니거나 플러그인이 켜지지 않으면 테스트를 중단하고 로그의 빨간 줄을 보고한다.

## 설치

1. 서버를 끈다.
2. `janhae-1.0.0.jar`를 서버의 `plugins` 폴더에 복사한다. 예전 jar가 있으면 교체한다.
3. 서버를 켠다. 콘솔에 `잔해 플러그인이 켜졌습니다. 아이템 49종.`이 보여야 한다.
4. 한 번 켜진 뒤 생기는 `plugins/Janhae/config.yml`에서 아래처럼 고친다. 클라이언트와 서버가 같은 컴퓨터일 때의 주소다.

```yaml
resource-pack:
  enabled: true
  bind: "0.0.0.0"
  port: 8765
  public-base-url: "http://127.0.0.1:8765"
  required: false
```

5. 서버를 다시 켠다. 콘솔에 `리소스팩 주소: http://0.0.0.0:8765/janhae.zip`가 보여야 한다.
6. 마인크래프트 26.3 클라이언트의 리소스팩 폴더에도 `janhae-pack.zip`을 넣고 켠다. 서버가 팩을 물어보면 수락한다. 둘 중 하나만 되어도 모습은 적용된다. 겉모습이 바닐라 나무검 그대로면 팩이 안 켜진 것이다.

## 확인 순서

각 항목은 기대한 결과가 보이면 통과다. 아니면 실패로 적고 계속한다.

1. 처음 접속하면 실명과 무적이다. 화면 타이틀은 `직업을 선택하세요`. 채팅은 두 줄이고, 둘째 줄의 `[ 연구원 ]` `[ 생존가 ]` `[ 요리사 ]`를 누를 수 있다.
2. 연구원을 누르면 설명과 `[ 확인 ]` `[ 다시 선택 ]`이 나온다. 다시 선택을 누르면 처음 두 줄이 돌아온다. 그 다음 생존가를 누르고 확인한다.
3. 실명이 풀린다. 오른쪽에 `잔해`, 레벨 1, 경험치 `0 / 150`, 직업 생존가, 머니 300, 방어력, 공격력이 보인다.
4. 인벤토리에 진압봉 1, 붕대 4, 연구소 식량 2가 있다. 진압봉은 나무검 모양이 아니라 검은 막대처럼 보인다.
5. `/메뉴`에 시설 버튼이 나오고, 상점을 눌러 연다. 각목(40)을 산다. 머니가 260이 되고 각목이 들어온다.
6. `/대장간`을 연다. 각목을 가운데 칸에 넣고 강화를 누른다. 돈이 줄고, 인챈트가 붙거나 각목이 사라진다. 바닥 블록은 그대로다.
7. 콘솔 또는 채팅에서 본인 닉네임으로 실행한다.

```
/janhae admin give <닉네임> infected_tissue 8
```

`/제작소`에 감염 조직 8개를 넣고 제작한다. 배양 파편 또는 대퇴골 둔기 중 하나가 나온다.

8. `/창고`에 아이템을 넣고 닫았다가 `/창고`로 다시 연다. 그대로 있다. `/창고 2`는 다른 페이지다. 1페이지 물건이 2페이지에 섞이지 않는다.
9. `/janhae admin give <닉네임> sealed_sample 1` 후 `/감정소`. `???`를 넣고 즉시 감정(2,000)을 누른다. 돈이 부족하면 `/janhae admin money <닉네임> 5000` 후 다시 한다. 인챈트가 붙은 장비가 나온다.
10. `/전당포`에 상점 각목을 넣고 판매한다. 가격의 40%가 머니로 들어온다. `???`는 팔리지 않고 칸에 남는다.
11. `/janhae admin money <닉네임> 200000` 후 `/암시장`. 전설 3칸이 보인다. 하나를 산다. 그 칸이 품절이 되고, 같은 물건을 다시 살 수 없다.
12. `/도감`을 연다. 아직 모르는 항목은 `???`다. 생존으로 좀비를 잡아 본다. 잡은 종류가 도감에 이름으로 나타나고, 경험치와 머니가 오른다. 좀비나 스켈레톤은 맨몸이 아니라 방호복, 진압 장비, 가죽 옷 차림으로 나온다.
13. 아직 생존가인 상태에서 `/요리`를 연다. 요리사만 할 수 있다는 메시지가 나오고 창은 열리지 않는다.
14. `/janhae admin reset <닉네임>`으로 직업을 지운다. 다시 실명 선택이 나온다. 이번에는 요리사를 고른다. 후라이팬, 연구소 식량 8, 끓인 물 2를 받는다.
15. `/janhae admin give <닉네임> infected_tissue 10` 후 `/요리`. 감염 조직 연구에 8개가 쓰이고 조직 구이 레시피가 열린다. 남은 재료로 조직 구이를 만든 뒤 먹어 본다. 허기와 체력이 찬다.
16. 다시 리셋하고 연구원을 고른다. 실험실 커터, 채집 키트, 식량 6, 붕대 1을 받는다. 채집 키트를 오른클릭하면 경험치가 오르고, 바로 다시 누르면 남은 초가 나온다.
17. 모루에 잔해 무기를 올리면 결과가 나오지 않는다. 조합대가 아니라 모루다.

## 보고

테스트가 끝나면 이 형식으로만 답한다.

```
서버: Paper 버전 / Java 버전
플러그인 로드: 성공 또는 로그의 오류 한 줄
리소스팩: 적용됨 또는 바닐라 모습 그대로

통과: 번호
실패:
- 번호: 기대한 것 / 실제로 보인 것 / 로그가 있으면 그 줄
못 함: 번호와 이유
```

코드를 수정하거나 커밋하지 않는다.
